## Crewbox — coworkers IA en local

Le dossier [`crewbox/`](crewbox/) contient un clone local de [Rerun](https://rerun.build) : des coworkers IA autonomes (soul, skills, mémoire, apps MCP, cron, webhooks, approbations humaines) et une API MCP compatible. Voir [`crewbox/README.md`](crewbox/README.md) et le [rapport de reverse engineering](crewbox/docs/REVERSE_ENGINEERING.md).

```bash
cd crewbox && npm install && npm start   # → http://127.0.0.1:4747
```
